A fast, dependency-free static site generator. It mirrors the reference
makefun-site 1.0.0 rule for rule (front matter, Markdown subset, template
dialect, slug/date/report rules) while speeding up the hot paths: bulk
inline rendering, compiled templates with an interpreter fallback, and
scan-based counting — about 2.1x faster with identical output.

## Run it

```sh
node --experimental-strip-types main.ts
```

Reads `/input/cases.json` and writes `/output/answers.json` via `run()` in
`solve.js`.
